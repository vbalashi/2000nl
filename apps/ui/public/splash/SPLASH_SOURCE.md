# Splash Source

These `apple-touch-startup-image` PNGs are generated locally using ImageMagick.

Design:
- Background: `#F5F7FB`
- Primary: `#2e2bee`
- Text: `#0f172a`
- Font: Noto Sans (Black)

Files in this folder are referenced from `apps/ui/app/layout.tsx` via `rel="apple-touch-startup-image"` with device-specific media queries.

V2 (#630): versioned assets on uniform #202124, regular Inter wordmark
at 52 logical pixels, accented nl. No inset icon square. Static native
splash cannot consume page cookie or run the dot animation.
