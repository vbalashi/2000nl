# Language catalogue

Source: SIL International ISO 639-3, https://iso639-3.sil.org/sites/iso639-3/files/downloads/iso-639-3.tab
Retrieved 2026-09-28. 7,927 records. Reference names and ISO codes are unchanged; `code` uses Part1 where provided and Id otherwise. This is an application lookup dataset, not a claim that every language or dialect in the world has an ISO code or validated LLM support. Russian search aliases use browser Intl.DisplayNames.

Source terms: https://iso639-3.sil.org/code_tables/download_tables

Search preserves Part1, Id, Part2b and Part2t code aliases. Exact code matches rank first, case-insensitively.
