# Code, dictionaries and services

## The open part

The application code, public documentation and demonstration data are available
under [Apache 2.0](LICENSE), except third-party components with their own terms.

This includes the database structure, dictionary data formats, shared types,
validation and supported language-specific fields. A format can serve several
dictionaries; different languages can share common fields and add their own.
An open format does not give permission to copy someone else's dictionary.

## What is separate

Full dictionaries, private user libraries, generated audio, private translation
prompts and dictionary creation tools are not included. Translation prompts are
supplied privately to the server. Test examples are not the hosted service's
translation instructions.

The code license does not provide access to the hosted app, paid services,
dictionary downloads or a paid API. These have separate terms.

records do not become public just because the application is open source.

and service terms.
