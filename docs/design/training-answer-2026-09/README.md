## Что уточнил владелец

### D1 — направление принято, не blanket approval

30.95.08 (Answer / `twUIm`) и 30.95.09 (Long / `lkphz`) подходят как основа интервалов и типографической иерархии.
Отсутствие иконки раздела и вертикальной линии в образце не означает их удаление из приложения.
Эти элементы существующей общей структуры сохраняются. Уплотнение области над словом не принято.

В первый реальный образец предлагаем перенести измеренные 8 px над словом, 44/20 px для слова/артикля,
16 px для основного примера. Набор не считается уже внедрённым или финально принятым в браузере.
Определение уже имеет 16 px в коде, а пример уменьшен отдельной веткой до 13 px: нельзя исправлять проблему
одним глобальным увеличением всех шрифтов. Роли вложенных примеров/пояснений проверяются отдельно.

### D2 — границы прокрутки определены

Training: сверху карточки остаются чипсы/действия, слово и его перевод; после них прокручивается содержимое.
Кнопки ответа, внешняя шапка/нижняя статистика и строка сессии не уезжают вместе с текстом.
Это семантические области, а не фиксированный `top: 130px`: высота заголовка зависит от переноса длинного слова и перевода.
Исчезающий перевод не оставляет пустую строку. Fades отображаются только при наличии скрытого содержимого
соответствующего края, не перехватывают ввод; точный размер ещё не выбран.

На коротком экране и при увеличении текста нужно отдельно проверить, остаётся ли полезная область чтения.
Предложение по доступности: если закреплённые области уже не помещаются, допустить доступную прокрутку,
а не обрезать текст или накрывать его кнопками. Это исключение нуждается в следующей приёмке, не выдано за утверждённое поведение.

Word Details: основной frame найден — `cCXBF`, полный номер `30.50.02`, 1440×960.
Прежняя неоднозначность была вызвана повторением префикса во вложенных слоях/копиях, не несколькими основными frames.
Подпись самого frame уточняет `IA ONLY · CARD USE 10.32.01`: организация экрана не утверждает старую типографику карточек внутри.
Фиксированная верхняя часть; левый список слов и правое содержимое прокручиваются независимо.
Vormen / Bronnen / Notities — переключаемые разделы дополнительной информации выбранной статьи.

Общие формы и грамматика должны относиться к словарной статье и быть доступны из каждого её значения.
Нельзя склеивать разные статьи только по написанию + части речи: существуют омографы/разные источники.
Нельзя повышать специфическую заметку/источник одного значения до общей информации всех значений.
Сейчас typed `wordDetails.entryId` и часть notes привязаны к отдельной entry; формы проецируются из entry raw.
Правильная общая проекция — отдельное согласование данных #70/#84/#252, не изменение identity в визуальном PR.

### D3 — наглядный контракт и небольшие шаги

Числа извлекаются из условно принятого образца и показываются с линиями и соответствующей таблицей.
Новые варианты дизайна root может предлагать самостоятельно; пользователь оценивает небольшие законченные части.
Один реестр измерений + иллюстрации + проверки вместо ADR на каждое число.

Из source измерены screen 402×874, card 382×540, padding 18, app header 58, session header 52,
review dock 120 (две строки кнопок по 42 с промежутком 6 и secondary actions), footer 44.
Последние внешние размеры — наблюдение, не разрешение скопировать неудобную двухстрочную статистику или тёмный header в light.
Точные width threshold/max-height для нового desktop из mobile-макета не выводятся.
Проверочные ширины 320/402/768/1440 — не автоматически выбранные breakpoints.
