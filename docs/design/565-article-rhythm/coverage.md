# Проверка остальных секций

Локальное предложение #565; production не изменён. Общие компоненты рендерят богатый `goed` и usage из `aandoen`. Данные — существующие audit fixtures: голландский исходный текст, авторские русские переводы для goed и английские для aandoen. Сетевые API и запись прогресса запрещены в capture.

| Вариант | Что проверяется |
|---|---|
| Определение + перевод | Перевод на одной оси с исходным текстом; отдельный размер определения сохранён |
| Синонимы / антонимы | Заголовок левее текста; rail и поля сохранены; leading согласован с литературным текстом через общий токен |
| Примеры | Rail, перевод на той же оси, переносы, интервалы между элементами |
| Usage | Самостоятельная секция usage-pattern, собственный rail, переводы off/on/partial |
| Выражения | Исходный текст с переводом и дочерними блоками |
| Explanation / Example внутри выражения | Заголовки на общей оси; содержание и перевод на 8 px правее |

Сетка: 2 fixtures × 2 ширины (390/695) × 2 размера текста (обычный/максимальный) × 2 профиля × 3 состояния перевода = 48 комбинаций. [Измерения](coverage.json) записывают inset, выравнивание перевода, leading и переполнение. Это дополнительная проверка исправленного предложения; прежние 432 комбинации относятся к предыдущему проходу вертикального ритма.

Проверки исключают горизонтальное переполнение, обрезание раскрытого перевода, потерю отступа вложенных заголовков и расхождение левых осей исходного текста/перевода. Проверяется наличие обеих секций отношений и usage, чтобы отсутствие контента не давало ложный успешный результат.

## Ограничения

- ArticleSenseRelations сейчас не принимает переводы отношений. Поэтому off/on переключает окружающий текст, а отдельный перевод синонима или антонима здесь не проверен и не реализован.
- Глобальный выбор увеличенного секционного интервала при частичных переводах остаётся известным вопросом: соседние непереведённые секции тоже могут получить этот интервал. Нельзя считать все комбинации окончательно настроенными.
- Геометрия DOM не измеряет точную границу нарисованных букв. Визуальные снимки необходимы наряду с числовыми проверками.
