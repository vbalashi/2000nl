# Требования к системе публикации

Статус: заготовка; блок ещё не проработан.
Создано: 2026-10-10.

## Задача

Сформировать требования перед выбором движка и технической реализацией.

## Уже известно

- Оригиналы хранятся на собственном сайте.
- Высокое качество типографики и чтения — основное требование.
- Несколько авторов, основной язык английский; возможны русские материалы.

## План проработки

- [ ] Авторский процесс: написание, редактура, предпросмотр, публикация.
- [ ] Типографика длинной статьи на телефоне и компьютере; изображения и код при необходимости.
- [ ] Хранение исходников/изображений, резервные копии, экспорт и переносимость.
- [ ] Авторы, рубрики, адреса статей, поиск, метаданные, доступность и производительность.
- [ ] Нужны ли рассылка, подписная база, RSS, комментарии и какие из них нужны сразу.
- [ ] Повторная публикация на внешних площадках; актуальные возможности проверить.
- [ ] Стоимость, обслуживание и интеграция с существующим сайтом.
- [ ] Сравнение движков по реальной статье после согласования требований.

## Ожидаемый результат

Приоритетный список требований и критерии выбора; затем отдельное исследование движков.
