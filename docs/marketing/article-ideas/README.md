# Банк идей статей

Происхождение идеи отделяем от автора будущей публикации и её статуса. Одобрение ведения банка или просьба о brainstorming не означает одобрения каждой предложенной темы.

- **Материал пользователя:** темы, выделенные из его рассказов и предложений. Заголовки сформулированы Codex; это ещё не обязательно заявленный пользователем замысел статьи.
- **Предложения Codex:** самостоятельно предложенные темы и ракурсы, включая выводы из резюме. Для просмотра, без включения в авторский план по умолчанию.
- Если пользователь явно предлагает тему статьи, отмечать «Прямая идея пользователя» и сохранять его формулировку. Если происхождение неясно, писать «Требует уточнения», а не приписывать авторство.

Статусы: идея → заготовка (есть план, ещё без отбора) → отобрана → черновик → готова → опубликована; также отложена. Сохраняем стабильные ID, дату/ссылки публикации, оригинал и адаптации. Ранжирование и отбор первой серии отложены.
