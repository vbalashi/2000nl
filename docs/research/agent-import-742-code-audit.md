## Recommended acceptance boundary

First increment: bounded pasted text, deterministic extraction/version and candidate positions; user-scoped exact lookup; explicit review of exact entry/sense choices and misses; one manual collection; start training through existing collection flow. No provider generation is necessary to prove the first end-to-end slice. A miss remains visible and retryable rather than becoming a generated entry automatically.

An import result should record candidate ID, original surface/offset/context, normalized lookup query, language/scope, selected entry identity, resolution reason, action event IDs, membership outcome and failure reason. A durable operation key must distinguish new attempt from retry. Membership replay can reuse existing no-op insertion; enrollment can reuse provenance idempotency. Do not infer that either supplies a whole-import transaction. Track per-item partial success and resume from durable outcomes.

Undo should remove only membership created by this import and preserve pre-existing membership, user entries, learning state, and later independent edits. Generated-entry deletion/enrollment undo need separate explicitly scoped semantics; existing remove-from-list is insufficient to promise global undo. Add tests for user A/B isolation, exact phrase versus example-only occurrence, ambiguous senses, private/base mixture, duplicate retry, partial failure and interrupted resume before introducing background orchestration.

Then add reviewed personal generation using the existing draft/save contract, then in-app conversation/tools around these domain operations. YouTube extraction belongs to AudioFilms; web/PDF adapters should produce the same artifact/occurrence contract. The agent must not own dictionary truth, training scheduling, or source access policy.
