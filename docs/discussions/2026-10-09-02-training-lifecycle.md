# Единый жизненный цикл Training

Дата: 2026-10-09. Источник: сообщение владельца в Codex, #647.

## Вопрос и позиции

После завершения пяти идиом главный экран показывает In Progress, 0 done,
5 remaining и Continue training. Владелец указал, что исправление только
идиом оставляет разрозненные правила для разных типов тренировки.

Диагностика: отдельные компоненты meaning, idiom и legacy sentence хранят
прогресс по-разному. Тест с настоящими TrainingScreen и TrainingIdiomSession,
но замоканным API, воспроизводит лишний Continue после серверного completed.
Повторная выдача тех же идиом реальным сервером пока не подтверждена.

## Направление и статус

Требование владельца: общее правило обработки для всех типов тренировок.
Владелец дополнительно прямо попросил один общий блок кода при завершении.
Реализация агента: общий контракт прогресса и терминальности,
общая передача прогресса из exercise-компонентов и одна проверка возможности
продолжения. Отдельные загрузчики содержимого и серверные планировщики сохраняются.

Незавершённая сессия продолжает текущий run с актуальным счётчиком.
Completed/exhausted не предлагают Continue и очищают browser resume record;
exhausted может иметь меньше выполненных карточек, чем первоначальный план.
Ошибки транспорта не означают завершение. Новая тренировка — явный новый run.

Статус: требование общего правила принято к работе; реализация и проверка
в #647, ещё не выпущено. Это ограниченное исправление существующей
семантики, связанное с дальнейшей декомпозицией resume/reconciliation #612.

## Открыто

Проверка фактического повторения идиом на production; выпуск после review.
