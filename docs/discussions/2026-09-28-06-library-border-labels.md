# Library: подписи ролей в границе блока

2026-09-28, Browser-комментарий владельца: попробовать Explanation в верхнем разрыве рамки и Example в горизонтальном разделителе, чтобы не занимать отдельные строки.

Реализована ось roleLabels=border|inline (Nested labels). Border применяется к hybrid с Clear pairs / Literary example. Один общий nodeRole остаётся в DOM; меняется позиционирование. Мягкий блок имеет тонкую рамку, подпись Explanation прерывает верхний край, Example — внутренний разделитель. Сохранены выбранный Literary example, порядок оригинал/перевод и данные. Новый вариант предложен для сравнения, не объявлен окончательно принятым.

Typecheck, focused lint и визуальная проверка desktop/412 px прошли. Перекрытия исходного текста подписями в проверенных блоках нет. Только dev-прототип.
