# Сохранение обсуждений и текущих решений

Дата: 2026-09-25. Источник: текущая задача Codex, запрос владельца после
согласования очереди предложений. Участники: владелец продукта и Codex.
Это содержательный конспект, не дословная стенограмма.

Владелец отметил, что повторные обсуждения постепенно формируют рабочую схему,
но причины решений теряются в чате. Попросил сохранять каждое обсуждение отдельным
документом с датой и темой, не переписывая старый документ при пересмотре.
Из обсуждений нужно выделять краткие действующие решения со ссылками на основания.
Актуальный документ должен обновляться и содержать действующее состояние,
без встроенной исторической хроники. Эта практика должна стать правилом harness.

Принято: неизменяемый архив обсуждений + обновляемый краткий реестр решений +
ADR для архитектурных границ. Повторная дискуссия получает новую запись со ссылкой
на прежнюю; принятое изменение отражается в актуальном решении. Предложения,
принятые решения и выполненная реализация обозначаются раздельно.
