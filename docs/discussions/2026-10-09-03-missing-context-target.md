# 2026-10-09 — Пропавшая подсказка первой карточки Translation

Источник: владелец попросил отдельно расследовать первую карточку после уточнения
[видимости перевода на обороте](2026-10-09-02-translation-recall-target.md).

Read-only проверка нашла точное предложение у `bedenken` (значение `iemand bedenkt zich`),
entry `144670fa-c4ce-4c38-86d1-44dd4560d075`: `ik ga niet met je mee; ik heb mij bedacht`.
Сохранённый русский primaryText — «передумать», перевод примера совпадает со скриншотом.
OpenAI translation updated_at: 2026-10-09 22:23:25.559 Europe/Amsterdam, непосредственно
перед скриншотом 22:23:42. Перевод существует; удаление данных не наблюдалось.

Подтверждённый кодом и регрессионными тестами дефект: обычный training lookup и
подготовка context example загружаются независимо. Второй путь может обновить
перевод, но возвращал только предложение. Face продолжал брать headword translation
из первого, более раннего model. Поэтому после успешного обновления предложения
подсказка слова могла отсутствовать. Совпадение времени обновления со скриншотом
поддерживает эту причину для отчёта; исторического browser payload нет, поэтому
точную последовательность запросов задним числом не доказать.

Исправление в #649 / PR #651: context prompt передаёт также свежий перевод точного
значения на запрошенном языке из того же результата загрузки. Face и Answer используют
его вместо старой копии; переключатель видимости также учитывает свежий перевод.
Проверяем status, freshness, entry identity, target language и непустой текст.
Допуск карточек, генерацию переводов, планировщик и БД не меняем. Это дополняет
первое исправление общей видимости, а не заменяет его. Проверка владельцем и публикация ожидаются.
