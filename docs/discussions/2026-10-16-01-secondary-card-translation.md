# Два независимых языка перевода карточки

Дата: 2026-10-16. Источник: обсуждение с владельцем; исполнение [#716](https://github.com/vbalashi/2000nl/issues/716).

Владелец запросил основной и дополнительный языки перевода для параллельного чтения, например русского и английского при изучении нидерландского.

Принято: каждое поле независимо поддерживает Off или выбранный язык. Допустимы оба Off, любой один включённый и оба включённых. Дополнительный язык используется только в переводе полной карточки — в словаре и на обороте тренировочной карточки. Вопросы обратных упражнений используют только основной язык; дополнительных подсказок нет. Учебная логика и FSRS не меняются. Существующий запрос/раскрытие перевода показывает включённые языки в порядке основной → дополнительный. Совпадающие языки достаточно показать один раз.

Предложение ассистента использовать дополнительный язык как подсказку в обратной тренировке отвергнуто владельцем. Оно не является принятым поведением.

Владелец разрешил реализацию в отдельной ветке и требует показать итоговый интерфейс в тестовой среде. Выпуск — только после его проверки. На момент записи решение принято, реализация ещё не завершена.
