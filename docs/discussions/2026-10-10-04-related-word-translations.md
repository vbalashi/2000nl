# Переводы синонимов и антонимов — 2026-10-10

Источник: принятый спринт #655 и «Поехали дальше» владельца после выпуска этапов2–3.
Решение принято; реализация ещё не завершена. Предыдущие решения:
[спринт](2026-10-10-01-translation-sprint.md),
[единый запрос](2026-10-10-02-translation-equivalents-literal.md).

Диагностика: связанные слова отсутствуют в provider request и JSON overlay;
публичные lexicalRelations и общий renderer передают только исходный текст.
Нормализованная ревизия кеша пока не учитывает synonyms/antonyms.

Владелец изменения — dictionary translation contract/artifact и публичная
lexicalRelations projection. Включать только существующие связанные слова
текущего значения в тот же ограниченный запрос; не генерировать новые связи.
Переводить именно связанное слово, выбирая его смысл по definition/context,
а не подставлять перевод headword всем синонимам. Дословность только для idiom.
Сохранять точную связь с типом/позицией, языком, исходной ревизией и prompt policy.
Исходные слова остаются видимыми; перевод рядом в скобках под общей кнопкой
перевода, одинаково в Training/Library. Отсутствующий перевод не выдумывается.
Нормализованные списки trim/dedupe едины для запроса/идентичности/проекции;
пропуски ограниченного запроса не сдвигают сохранённые позиции.

Новый immutable prompt на базе выбранного v8/high, сравнение с ним на связанных
словах и регрессиях; полный JSON/identity/UI путь покрывается тестами. Один
запрос, без SQL migration и массовой регенерации. Старый v8/high сохраняется как
точный профиль отката. Выпуск, оценки и cleanup отслеживаются в #655.
