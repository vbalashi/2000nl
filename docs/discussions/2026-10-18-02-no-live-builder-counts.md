# Session Builder без живых счётчиков

Дата: 2026-10-18. Источник: продолжение совместного просмотра локальных экранов
владельцем в Codex. Issue #712 / PR #749.

Уточняет [предыдущее обсуждение](2026-10-18-01-empty-training-guidance.md).
Первоначальный вариант текущего PR показывал три счётчика внутри Session и
пересчитывал их при изменениях черновика. Владелец отклонил этот вариант:
дополнительные запросы медленные, а блок визуально нарушает раздел настроек.

## Принято и реализуется

- Счётчики остаются только на главной карточке Training.
- Настройка источника, упражнений, фильтров, размера и баланса не запускает
  availability-запросы; существующий hook включён только на главной.
- Редактор может повторно использовать уже полученный на главной снимок, только
  для того же владельца, языка и нормализованной области материала/упражнений/
  фильтров. Размер и баланс применяются к этому снимку без нового чтения БД.
- После изменения области старый снимок не определяет пустоту черновика. Если
  подходящего снимка нет, Start остаётся доступным; его авторитетный результат
  сообщает об отсутствии карточек через исправленный экран Training.
- При известном ограничении Reviews only в Session остаётся короткая подсказка
  рядом с настройками. Без счётчиков и без дополнительных абзацев в footer.
- На главной сохраняется объяснение справа от кнопки шрифтом подписей счётчиков.

## Проверка

В локальном Chrome изменение размера и режима после открытия Session не
отправило сетевых запросов. Тест дополнительно запрещает включение availability
при настройке фильтра, размера и баланса. Не показывать прежние скриншоты со
счётчиками в редакторе как итоговый вариант. Выпуск остаётся отдельно от принятия.
