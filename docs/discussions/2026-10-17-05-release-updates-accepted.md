# Принят переработанный интерфейс обновлений, применить #299

Дата: 2026-10-17. Источник: владелец в Codex: «считаем, что так более-менее…
в таком виде зафиксируем, применяй» после просмотра переработанных экранов и
уточнения назначения обеих ссылок Read more.

Обе ссылки Read more ведут в одну статью о релизе вне приложения. Ссылка и
новость необязательны; редакционный контент пока null, без выдуманных публикаций.

Применение выполняется через PR729 и обычный main→NUC deployment pipeline после
успешных проверок. Изменение автономно, DB-миграций/новых секретов не требует.
Реальные Android/iOS standalone проверки остаются ограничением покрытия;
предыдущий desktop/browser production-pair QA не объявляется их заменой.
