# Автоматический shortlist DUCAME

2026-10-19. Статус: разрешённый внешний эксперимент, продолжение [первого пилота](2026-10-19-01-ducame-mwefinder-pilot.md). Источник: владелец попросил продолжить после демонстрации одного выражения.

Проверяем автоматический выбор канонических форм по готовому lemma-index, затем строгие структурные запросы на прежних 32 предложениях. Вход отбора — только слова/леммы предложения, не эталонные выражения. Альтернативы лемм и кратность проверяются; исходные деревья уже закешированы. Лимит 96 уникальных канонических кандидатов, последовательные запросы к публичному парсеру с таймаутами; никакого полного перестроения индекса или импорта indexes. Платных моделей, записи в БД и обновления коллекций нет. Результат остаётся исследовательским: ограниченные варианты лемм, targeted reference и неоднозначная лицензия исключают production-readiness claim.
