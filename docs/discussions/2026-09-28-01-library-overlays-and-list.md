# Library: всплывающие действия и состав списка

Дата: 28.09.2026. Конспект 11 браузерных замечаний владельца; не стенограмма. Продолжение [матрицы компонентов](2026-09-27-02-library-component-matrix.md). Реализация остаётся локальным прототипом.

## Замечания и реализация

1. 2K: уменьшена высота подложки с 18 до 14 px. Шрифт 10 px, соседний POS 11 px; увеличения шрифта не было.
2. Collections всегда показывает `· N`, включая ноль. Число отражает membership текущего значения.
3. «…» открывает плавающее меню Report / Mark as known / Exclude, без увеличения карточки. Пункты 44px, рамка/фон hover/focus и press feedback; Arrow keys, Home/End, Escape, outside dismissal. Меню через portal, не обрезается scroll-контейнером.
4. Видимая строка Library удалена. H1 остаётся visually-hidden для семантики, активная навигация указывает раздел.
5. В hybrid линия охватывает фразу и связанный soft block целиком.
6. Иконки заголовков Examples и Expressions & usage возвращены.
7. Высота 28px принята владельцем. Добавлены neutral / exact accent / darker accent для текста оценок. По расчёту на белом фоне исходные оттенки дают контраст 1.51–2.69, тёмные родственные — 5.12–6.24. Визуальная рекомендация агента — darker accent; окончательный выбор владельца ещё нужен. Тон текста и засечка задаются одними локальными semantic tokens.
8. Разделительная линия под header статьи убрана.
9. Collections — отдельный native dialog с затемнением/blur, поиском, множественным выбором, созданием и автоматическим добавлением в новую коллекцию. Общий provider хранит каталог и memberships между открытиями/закрытиями разных статей в пределах стенда. Все значения/счётчики — fixture/demo, не DB.
10. В toolbar Learn занимает отдельную строку, Collections и «…» стоят ниже. Сравнение ширины: 100% либо 84% (8% отступы с каждой стороны). Четыре оценки остаются на этом же месте.
11. В списке первая строка — только слово/артикль, вторая — POS с точкой, 2K и источник. Независимое сравнение `listing=metadata|counts|preview`. Counts подписаны meanings, не выдаются за homonym number. Preview показывает первое определение только в явном экспериментальном варианте. При открытых деталях и на mobile источник/count/preview скрываются, сохраняются word/POS/2K. Плотность Compact/Reading остаётся отдельной настройкой. Состав списка владельцем пока не утверждён.

## Компоненты и ограничения

Добавлены CardActionMenu, LibraryModal, CollectionPicker, DemoCollectionsProvider в prototype UI. LibraryModal используется коллекциями и Report; общий каталог и memberships принадлежат LibraryPrototype. Production компоненты, capabilities, исключения и сохранение прогресса не менялись. Report, learning actions и ratings по-прежнему ничего не отправляют. Конфигурация вариантов остаётся в libraryStudy.ts, публичные schema/DB-контракты не менялись.

## Проверка

Typecheck и целевой lint. Browser 1024×768 и 412×915: меню не изменяет высоту статьи (450.6875px до/после), клавиатурное закрытие, коллекции search/create/select, membership сохраняется после закрытия/повторного открытия деталей, полный и узкий список. Main 840px, горизонтального переполнения нет. Расчёт контраста выполнен по sRGB luminance. Полный accessibility-аудит и production-интеграция не проводились.
