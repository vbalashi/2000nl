# Большой бюджет и точечное восстановление объяснений

Дата: 2026-10-11. Источник: обсуждение с владельцем, #655, PR #670.

Принято: перенести проверенные 32768 completion tokens и таймаут 180 секунд
в словарный перевод Luna6. Основной v8 не менять. Для завершённого ответа,
в котором отсутствуют только обязательные idiom-explanation, проверить
единственный дополнительный запрос с полным исходным контекстом, предыдущим
ответом и явным списком пропущенных полей. Сохранять уже переведённые поля;
объединённый результат обязан пройти обычный строгий контракт.

Восстановление не запускается для обрыва JSON, дубликатов, неизвестных полей,
других дефектов. Порядок сохранённых полей нормализуется по fieldId без изменения значений. Транспортные повторы остаются отдельными.
Логи содержат тип операции и количества полей, без исходных текстов.
Реализация и живой тест трёх сохранённых ответов следуют этому решению.
