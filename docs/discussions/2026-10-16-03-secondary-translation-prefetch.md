# Предзагрузка дополнительного языка карточки

2026-10-16. Источник: владелец после выпуска #722 спросил о предзагрузке обоих языков и разрешил реализацию и выпуск #723 без дополнительной приёмки.

Принято: дополнительный язык полной обратной стороны готовится на одну карточку вперёд. Расширять его до трёх карточек не требуется: он не участвует в вопросах/подсказках упражнений перевода. Адаптивная глубина основного языка остаётся прежней. Оба языка независимы, включая основной Off; совпадающие языки не дублируют запрос. Подготовка фонова, использует только доступные будущие члены текущей сессии и отменяется при смене области/языка или выходе. Не меняет выбор карточек, оценки, прогресс и вопросы. Ошибка одного языка не блокирует другой или показ карточки.

Владелец слоя: UI hook `useLatchedTranslationBuffer`, общий для ordinary/word-in-context и специализированных сессий. Используется существующий серверный механизм фоновой подготовки переводов; схема и API не меняются. Статус: принято; проверка и выпуск отслеживаются в #723.
