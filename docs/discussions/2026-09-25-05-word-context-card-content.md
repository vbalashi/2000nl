# 2026-09-25 — Состав карточки «Слово в контексте»

Источник: обратная связь владельца после проверки первой опубликованной карточки
нового режима. Это краткий конспект обсуждения, а не дословная стенограмма.

В первой версии Face показывал перевод выбранного примера и подсказку с частью
речи. Answer показывал headword и выбранный пример, но намеренно убирал
определение из обычной карточки значения. Владелец указал, что определение
нужно для понимания того, какое именно значение слова отгадывается.

Принятое уточнение: часть речи — отдельный компактный чип на Face; по кнопке
подсказки открывается определение того же Dictionary Entry. Answer сохраняет
определение, headword и ровно выбранный пример с переводом. Для всего остального
сохраняются существующие шаблон карточки, действия и планировщик.

Реализация: [issue #512](https://github.com/vbalashi/2000nl/issues/512).
