# Переводы карточек: план спринта

Дата: 2026-10-10. Источник: текущая беседа владельца, скриншот карточки de koe.
Это содержательный конспект. Владелец утвердил порядок и лёгкую среднюю точку
между вариантами перевода. Реализация и выпуск не считаются завершёнными.

## Принятые требования

1. На обороте идиомы показывать доступный перевод самостоятельного значения
   headword, например de koe — корова; перевод выражения остаётся отдельно.
2. Восстановить полезные эквиваленты одного значения. Разделитель — лёгкая
   средняя точка `·`, не точка с запятой. Не смешивать разные значения и не
   требовать дополнительные варианты, когда они неуместны.
3. Естественный перевод идиомы дополнять дословным, когда образ помогает
   пониманию. Он факультативен, помечен «дословно» с локализацией подписи.
   Буквальное раскрытие образа отличается от перевода без контекста.
4. Переводить синонимы и антонимы в контексте значения и на выбранный язык.

Порядок 1 → 2 → 3 → 4 принят. Даты окончания спринта не заданы.

## Технические наблюдения и предложения

Словарный контракт уже содержит primaryText, alternativeTexts и baseText;
Training и Library уже соединяют варианты через ` · `. Сначала исследовать,
где варианты исчезают, а не считать отсутствие в UI доказательством ошибки
промпта. Карточка идиомы пока вообще не передаёт entryTranslation в ответ.
Idiom-only sense намеренно не имеет самостоятельного перевода.

Для этапа 1 использовать только публичную проекцию: самостоятельное значение
текущей записи, а для idiom-only — первое самостоятельное значение той же
группы и части речи по meaningOrdinal. Не выбирать случайное значение по
наличию перевода; не использовать перевод идиомы вместо перевода слова.
Неполный/устаревший/чужой языковой кеш не отображать. Это техническое правило
реализации, а не дополнительное высказывание владельца.

## Открытые вопросы

Политика обновления старых переводов, контракт дословного поля, полнота
генерации связанных слов уточняются в соответствующих этапах. Массовое
пересоздание production-кеша пока не согласовано.
