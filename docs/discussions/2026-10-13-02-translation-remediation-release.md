# Исправление и выпуск Translation

исправить все выявленные недостатки по очереди, внедрить контекстный промпт,
проверить остальные пути старого кеша/пропущенной подготовки и развернуть
изменения с возможностью быстрого отката. Более широкое сравнение старых и
новых переводов на разных карточках владелец запросит отдельно.

Основание: [аудит](../research/2026-10-13-translation-rendering-audit.md).

Порядок: согласованность контекстной подсказки и оборота → серверная полнота
и клиентские входы подготовки/обновления → новый активный промпт с сохранённым
профилем отката → интеграционные проверки и review → штатный release,
health/worker verification, reference sync и retirement.

Lookup остаётся read-only; подготовка выполняется через существующую очередь.
Направление карточки, frozen example, FSRS и учебные действия сохраняются.
Массовый backfill не требуется: stale cache обновляется по текущему обращению.
Новый промпт учитывает прямо подтверждённые обычными примерами эквиваленты,
сохраняя право не добавлять альтернативы и не смешивая значения идиом.
