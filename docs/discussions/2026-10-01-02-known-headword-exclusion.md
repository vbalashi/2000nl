# Known и исключение headword из тренировок слов

Дата: 2026-10-01. Источник: ответы владельца в Codex, задача #407.
Статус: принятое правило; Exclude внедрён в миграции 192. Новые Known
становятся направленными в миграции 193; исторические парные отметки и их
отмена сохраняют прежнюю область без переписывания истории.

Known относится к конкретной карточке (значению) и направлению упражнения.
Отметка сохраняется между запусками, независимо от сохранённого пресета.
Это не исключение всего слова и не имитация оценки FSRS.

Exclude относится ко всему headword: все его значения исключаются из обычных
тренировок слов в направлениях слово → определение и определение → слово.
Владелец явно выбрал все обычные тренировки пользователя, а не только один
сохранённый пресет. Идиомы и переводы предложений этого слова не исключаются.
Аудио остаётся независимым; отдельная настройка пропуска исключённых headwords
для аудио в этот этап не входит.

Для реализации используем устойчивую идентичность статьи/Headword Group,
а не совпадение написания строки в разных словарях. Сервер разрешает эту
идентичность из выбранного entry; клиент не расширяет область списком UUID.
Новые значения того же Headword Group тоже должны попадать под исключение.
Исключение не меняет Known, FSRS, оценки или накопленный прогресс. Undo снимает
точную собственную отметку исключения без восстановления/перезаписи оценок.

Существующее exclude-pair сохраняет прежнюю область для старых клиентов и
отдельных семейств упражнений. Новый явный target headword должен использовать
отдельный атомарный серверный boundary с проверкой пользователя/доступа,
идемпотентности и, при действии из тренировки, текущего члена сессии.
Действие из Library не создаёт фиктивную тренировочную сессию.

Проверки: оба направления и соседние значения; иной headword/пользователь;
идиомы/предложения/аудио; новые запуски и уже составленная очередь; повтор
запроса, конфликт события, отмена и гонка с оценкой; отсутствие изменений
FSRS/Known; права доступа и отзыв доступа к словарю.

Конфигурация переводчика: владелец разрешил использовать основной
apps/ui/.env.local либо конфигурацию NUC. Локальный файл найден и скопирован
в worktree с правами0600; содержимое не фиксируется в Git или документах.
