# Согласованный выпуск #717–#720

2026-10-16. Источник: владелец после просмотра #716 разрешил выпуск с проверкой живого production и возможностью отката, с учётом других ожидающих PR. Исполнение: #721.

Принято объединить #717 (Library/focus), #718 (ошибка и повтор запуска), #719 (два независимых языка полной карточки) и #720 (планировщик SQL) в одном интеграционном PR, без промежуточных выпусков отдельных веток. Контракт включает 226, затем 227, с точными checksum и полной цепочкой postflight. Hold исходной #720 не обходится: её зависимость 226 присутствует в том же полном выпуске; сама исходная ветка не развёртывается.

Локальная демонстрация #716 была ограничена малым fixture-корпусом и отсутствием платного провайдера: VanDale 2k пуст в fixture, заранее подготовленные переводы только huis/fiets. Это не означает, что произвольные слова проверены. Владелец сообщает нули и ожидание переводов; окончательная проверка — на production после exact-SHA/contract health, на выделенном QA-аккаунте.

Выпуск требует исправить все выявленные ошибки CI. Откат не удаляет миграции/данные и не понижает DB receipts; совместимый revert сохраняет контракт227. Статус: выпуск разрешён, ещё не выполнен.

Проверка CI выявила различие окружений: plain PostgreSQL 17 включает JIT, production `SHOW jit` возвращает `off`. В отдельном PostgreSQL 17 с JIT on три scheduler RPC превысили 5 секунд (52 теста: 49 passed / 3 timeout); с JIT off тот же набор — 52 passed, 0.785 секунды выполнения тестов. FSRS workflow явно задаёт JIT off перед тестами, воспроизводя production без изменения ограничений времени или SQL миграции.
