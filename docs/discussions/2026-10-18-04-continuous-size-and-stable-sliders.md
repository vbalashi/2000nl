# Непрерывная сессия и стабильная геометрия ползунков

2026-10-18. Владелец повторно уточнил в Codex: без ограничения числа карточек,
после назначенных повторов — дальнейшая практика впереди расписания и циклическое
повторение до остановки пользователем. Предпочтительная отметка — ∞, без длинного
названия и повторяющихся пояснений.

Это соответствует принятому 2026-09-24 issue #468 (Continuous), который остаётся
открытым. Текущий `all-due-today` — конечный review-only проход; переименование его
в ∞ без реализации очереди было бы ложным обещанием. Ветка #712 не меняет этот
scheduler-контракт, не мигрирует сохранённые настройки и не подключает #468.

Непосредственно в preview #712 исправляется геометрия: approved size picker не
вставляет динамический абзац; заголовок Session и строки выбранных значений имеют
стабильную высоту. Мобильные подписи разделов не разрывают «Упражнения» пополам.
Два существующих ползунка сохраняются. Конечные размеры и их текущие значения
сохранены; реальный ∞ потребует отдельной реализации #468 и проверки FSRS,
повторных действий, изоляции области и takeover.

Локальная проверка: 390×844, после получения фокуса смена 5 → all-due даёт
координаты size 346.296875 → 346.3125, mix 478.109375 → 478.125; межцентровое
расстояние сохраняется 131.8125 px. При первом клавиатурном фокусе браузер может
сам прокрутить viewport — это отдельно от изменения геометрии компонентов.
58 профильных тестов прошли. Production не менялся; preview ожидает владельца.
