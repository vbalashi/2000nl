# Library: сохранить существующую структуру

Дата записи 26.09.2026, источник — текущая беседа Codex. Содержательный конспект, не дословная стенограмма.

После первой пробы владелец уточнил: общая Library приемлема, но придуманная упрощённая панель одного определения не подходит. Нужно использовать существующую структуру headword-group: POS, важный 2K, перевод и аудио, headword, отдельные карточки значений. Разные POS одного написания не объединять. Для следующего обсуждения взять реальные noun/adverb/adjective статьи goed. Внутренние карточки будут обсуждаться отдельно, их не следует переизобретать заранее.

Прототип теперь импортирует настоящий LibrarySenseCardGroup. Локальные исходные статьи a4439/a4441/a4440 дают 3/1/3 обычных значений с определением. Отдельные idiom-only записи не входят в этот обычный preview; это не заявленные production counts. 2K взят из исходного is_nt2_2000. Прогресс/переводы не выдуманы, кнопки внешних действий лишь показывают сообщение preview. Нужна последующая сверка всей production projection при интеграции.
