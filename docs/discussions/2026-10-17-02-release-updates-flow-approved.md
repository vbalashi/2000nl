# Принят флоу обновлений: точка, плашка и Updates

Дата: 2026-10-17. Источник: продолжение обсуждения в Codex.
Owning issue: #299. Статус: продуктовый флоу принят, runtime не реализован.

Владелец подтвердил: «Точка, плашка и updates в настройках» после объяснения
полного флоу. Это уточняет [предыдущее обсуждение](2026-10-17-01-release-updates-and-news.md).

## Принятый флоу

- В шапке сохраняются две кнопки: тема и настройки. Колокольчик не добавляем.
- При обнаружении обновления компактная плашка доступна на любой странице:
  краткий анонс, «Подробнее», «Обновить», «Позже». Во время активной тренировки
  её показ откладывается до завершения. Фоновая проверка версии продолжается.
- «Позже» скрывает плашку; переходы между страницами и polling не показывают
  её заново для того же релиза. Обновление остаётся доступным через настройки.
- На шестерёнке точка, пока клиент устарел либо есть непрочитанная новость.
- В настройках раздел Updates с такой же точкой. Внутри краткая новость,
  ссылка в блог, обновление, установленная/доступная версии, дата выпуска и
  ручная проверка обновлений. Отдельный About пока не вводим.
- Открытие Updates снимает непрочитанность показанной новости, но не отметку
  об устаревшей сборке. Прочитанность новости и обновлённость независимы.
- «Подробнее» открывает статью отдельно, без обновления приложения.
- «Обновить» выполняет безопасную полную перезагрузку и проверку результата;
  только подтверждённая актуальная сборка снимает необходимость обновления.
- Активный пункт навигации соответствует странице: Library в Library,
  Settings в Updates. Смешанный Library/Settings на сгенерированном макете
  был ошибкой изображения, а не утверждённой навигацией.

## Визуальные материалы

Выбор зафиксирован словами, а не номером: изображения пришли в другом порядке.
Согласована комбинация «плашка + точка + Updates», не отдельный колокольчик.
Изображения — приблизительные концепты, не точная спецификация приложения.
Телефон, состояния ошибок и точные отступы ещё требуют проработки.
