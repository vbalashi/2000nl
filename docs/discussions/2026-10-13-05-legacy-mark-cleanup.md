# Очистка старых hidden и click_count

Дата: 2026-10-13. Источник: владелец после [проверки zijn](2026-10-13-04-zijn-data-investigation.md), #688 / PR #689.

## Проверка предпосылок

hidden не удалён из runtime: selectors отбрасывают такие направления, а deployed handle_card_review всё ещё имеет ветку p_result=hide с EXECUTE для authenticated. Современный UI обычных значений использует Known для одного направления и meaning-wide Exclude для обоих; независимые exercise families имеют собственные исключения. Known не является оценкой FSRS. frozen_until — отдельная временная пауза, не старый hidden. На уровне старого Platform V1 также остаются hide/freeze review results. Полное удаление legacy write surface не выполнено этой очисткой.

Текущий AudioFilms SenseCard lookup передаёт intent=external-click в read-only lookup. Само нажатие на слово не записывает старый definition_click в обучение; явные Learn/Known/review идут отдельными actions. Это проверка текущего исходного кода, не наблюдение сетевого трафика production AudioFilms.

В аккаунте владельца обнаружено 29 hidden направлений, включая 5 с прогрессом; 146 карточек с суммарным click_count=189. В review log 164 legacy click events; на 18 карточках счётчик и журнал не совпадают, на 16 click_count превышает fsrs_reps. Нельзя вычитать click_count из FSRS. Показы и оценки также не обязаны совпадать: действующие Learn/record-view пути могут менять seen_count без оценки.

## Явное решение владельца

После сообщения о возвращении карточек в доступные для тренировки владелец выбрал: «Да, вернуть все 29 и обнулить старые счётчики». Отдельно повторил просьбу обнулить старые счётчики. Область — его аккаунт, все слова/карточки; другие аккаунты не затрагиваются. История, Known, современные exclusions и FSRS остаются.

## Выполнено и проверено

В production в одной транзакции изменены только hidden=false и click_count=0 у 173 пересекающихся записей. state_revision штатно обновлён триггером. Перед записью: блокировка только затронутых строк, проверка ожидаемых 29/146/189, защищённая локальная резервная копия, dry run с ROLLBACK. Trigger защиты Known не отключался; hidden+Known пересечений нет, четыре карточки Known затронуты только очисткой click_count.

До COMMIT сверены все прочие поля каждой затронутой карточки, неизменность Known/meaning/pair exclusions и полные checksum/count пользовательских review/action history. Проверки прошли. Независимое чтение после COMMIT: hidden_remaining=0, click_counters_remaining=0, click total=0; три active meaning exclusions сохранены.

Для первого значения zijn direct теперь 0/6/9; FSRS история сохранена. Для шестого значения hidden=false, счётчики нулевые. Не выполнены пересчёт расписания, удаление событий, reset всего обучения, изменение новой статистики UI или отключение legacy RPC.

Локальные непубликуемые материалы в активной рабочей копии: tmp/688-investigation/cleanup.sql, cleanup-dry-run.sql и private-backup/applied-before.json (173 строки; каталог 0700, файл 0600). Здесь содержатся персональные данные, в Git не добавляются. Рабочая копия остаётся владельцем recovery evidence до безопасного переноса/retirement. Не восстанавливать старый snapshot поверх более нового учебного прогресса; при необходимости восстанавливать только одобренные поля с проверкой текущей revision.

## Открыто

Устранить оставшийся старый путь активации hidden отдельным совместимым изменением; data cleanup сам по себе не является retirement API. Отдельно выбрать статистику ручных оценок, показов и legacy history; fsrs_reps по-прежнему отражает старые автоматические Again. Внешние × уже удалены в коде draft PR #689, выпуск ещё не подтверждён.
