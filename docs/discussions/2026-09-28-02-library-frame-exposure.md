# Library: принятые кнопки, метка в рамке и близкие метаданные

Дата: 2026-09-28. Источник: семь комментариев владельца в Browser.
Продолжение [предыдущего обсуждения](2026-09-28-01-library-overlays-and-list.md).

## Принято владельцем

- Learn во всю ширину предпочтительнее inset.
- Тёмные оттенки текста review-кнопок предпочтительнее цвета самой засечки.
- Меню через многоточие одобрено.
- Частям речи нужны разные цвета; в узком списке нужно сохранять число значений.

## Реализованные предложения для сравнения

- Общий NumberedMeaningFrame получил слот exposure: Repeat2 + New либо число × в разрыве верхней рамки справа. Номер остаётся слева; строка определения содержит текст и шеврон.
- Exposure label переключает рамку / прежнее место внутри строки. Сцена review показывает демонстрационные 3× при отсутствии repeatCount; это не реальная история пользователя.
- Sense count position переключает группировку рядом с метаданными / дальний правый край широкого списка. На мобильном и в узкой колонке счётчик остаётся рядом с частью речи и 2K; источник скрывается.
- Пустота сама по себе не заполняется: связанные сведения группируются слева, чтобы не требовать переноса взгляда через всю строку. Внешняя ширина секции не изменена.
- Общий Metadata задаёт цвет POS в списке и заголовке. Семейства взяты из apps/ui/docs/design-guide.md (noun blue, verb red, adjective green, adverb orange, preposition purple); приглушённые оттенки — предложение прототипа. Рабочий V2 пока имеет жёстко зелёную точку.

## Граница и проверка

Изменены только dev-прототип и его документация. Существующие общие компоненты рамки, метаданных, содержимого и действий используются всеми вариантами. Перенос в production остаётся отдельной работой.

Typecheck и lint изменённых TS-файлов прошли. В браузере проверены New с полной Learn, review с 3×, раскрытые/свёрнутые значения, мобильный экран 412 px и широкий 855 px; число значений видно в узком списке. Новые оси управляются общей таблицей studyAxes и сохраняются в URL.

Открыто: принять ли метку в рамке и близкий счётчик как окончательный вариант; точные оттенки POS ещё не утверждены.
