# Один перевод с первого раза, пересмотр по жалобам

Источник: пользователь, 10 октября 2026, после эксперимента #657 / PR #658.

Принятое продуктовое направление: один основной максимально качественный
промпт и один provider-вызов на обычный перевод. Не оплачивать judge, голосование
и повторную генерацию для каждой карточки. Жалоба о плохом переводе становится
входом для отдельного точечного пересмотра; повторяющиеся ошибки используются
для будущих offline eval/prompts. Это направление принято, автоматическая
очередь исправления ещё не реализована/не подтверждена этим исследованием.

Нельзя гарантированно определить спорный смысл одним дешёвым программным
валидатором. Формат/полнота/идентичность проверяются детерминированно; скрытые
семантические ошибки выявляются жалобами и выборочными offline проверками.
Самооценка уверенности модели не является доказательством правильности.

Предлагаемый следующий эксперимент: репрезентативные полные значения реальной
длины, единый компактный кандидат, сравнение трёх моделей по одному ответу на
вход, отдельная проверка механизма пересмотра. План и оценки цены:
Research/translation-eval/SINGLE-PASS-NEXT-EXPERIMENT-2026-10-10.md.
