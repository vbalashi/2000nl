# Дополнительный язык зависит от основного

2026-10-16. Источник: владелец во время #723 уточнил «второй язык не может быть активным если первый выключен»; на прямой вопрос подтвердил: «Новое правило: второй зависит от первого».

Принято: выключение основного языка выключает дополнительный; выбор дополнительного недоступен, пока основной Off. Изменение обоих сохранённых значений отправляется одной операцией настроек. Старые сохранённые комбинации primary Off + secondary language считаются неактивными в UI и предзагрузке. Повторное включение основного не включает дополнительный автоматически: его можно включить отдельно. Выключение дополнительного не влияет на основной.

Это заменяет независимое включение из обсуждения #716 и часть #723 про primary Off. Дополнительный по-прежнему используется только в полной карточке и предзагружается ровно на одну карточку вперёд. Вопросы, подсказки, расписание и глубина основного буфера не меняются. Реализация/выпуск включены в #723 / PR #724.
