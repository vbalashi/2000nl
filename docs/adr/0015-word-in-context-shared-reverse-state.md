# ADR-0015: Слово в контексте использует обычный reverse-прогресс значения

Статус: принято владельцем 2026-09-25; реализация проходит релизную проверку.
Основание: [обсуждение и явное принятие](../discussions/2026-09-25-03-word-in-context.md);
[уточнение состава карточки](../discussions/2026-09-25-05-word-context-card-content.md).
Заменяет модель очереди/отдельного FSRS предложений из ADR-0014 для следующего
пользовательского режима. ADR-0011 сохраняет смысл для идиом и существующих
самостоятельных translation targets, но не определяет идентичность этого режима.

«Слово в контексте» — вариант предъявления ordinary reverse (`definition-to-word`)
конкретного Dictionary Entry. Face показывает перевод одного его примера и чип
части речи; подсказка открывает определение этого значения. Answer — целевое
слово, определение, исходный пример и перевод. Примеры ротируются внутри
значения, без своего FSRS. Один ответ ровно один раз обновляет существующий
reverse-прогресс этого значения; direct и другие значения не затрагиваются.

Используем обычный планировщик и фильтры с необходимым допуском точного значения
и примера; не строим отдельное ранжирование предложений. Число примеров не
увеличивает частоту значения. Общие шаблоны и действия сохраняются, исключение
относится к паре направлений значения. Lookup/перевод/предзагрузка не пишут прогресс.

Способ предъявления и открытие подсказки — небольшие метаданные того же действия.
Это позволяет исследовать смешанную сложность подсказок без второго расписания.
Source node/fingerprint остаются идентичностью контента для перевода и evidence,
но не идентичностью нового FSRS. Highlight/alignment переводного фрагмента —
будущее улучшение, не MVP; непроверенная маска целевого слова недопустима.

Не конвертируем старый sentence FSRS в ordinary FSRS автоматически. Переход
сессий/пресетов и сохранение истории требуют явного контракта и тестов до выпуска.
