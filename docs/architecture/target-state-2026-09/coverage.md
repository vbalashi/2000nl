# Матрица экранов, состояний и визуального контракта

Версия документа: 0.1; 2026-09-05; #246. Это реестр покрытия решений.
Визуальная новая ревизия ещё не утверждена. Историческая база не становится новым контрактом автоматически.

## Как читать и расширять

Ключ строки: экран / режим / сторона / состояние / размер / тема / язык / ревизия.
Четыре независимые оценки: охват (сейчас/позже/неприменимо), решение (пробел/предложение/на ревью/утверждено/заменено),
измерения (пробел/извлечены/утверждены), runtime (не проверен/есть расхождение/проверен на SHA).
Статус реализации задачи здесь не хранится — ссылка ведёт в GitHub.

У строки указываются точные Pen node и revision, доказательство owner approval, ссылка на токены, fixture и проверенный commit.
Пропуск записывается «— / не определено», а не нулём или предполагаемым стандартом.
«Неприменимо» требует причины; «позже» остаётся видимым пробелом и не блокирует соседние готовые строки.
Наследование общих правил допустимо только явно: общий профиль + перечисленные overrides.
Утверждение mobile/dark не распространяется на desktop/light.

## Оси, которые нельзя потерять

| Ось | Предусмотренные варианты | Правило |
| --- | --- | --- |
| Режим | слово→определение; определение→слово; слушать→узнать; слушать→написать (позже) | Наличие варианта не доказывает его реализацию |
| Сторона | Face; Answer | Тело различается; каркас и общие действия согласованы |
| Учебное состояние | новое; в изучении; повторение; Known; скрыто/заморожено | Допустимые действия определяет Platform |
| Сеть/операция | initial loading; ready; saving; rejected; reconciling; accepted-next-loading; accepted-next-failed; next-ready; empty; complete | Empty, failure и complete не взаимозаменяемы |
| Перевод | off; ready; pending; failed; unavailable | Перевод не блокирует принятую оценку |
| Аудио | available; pending; failed; unavailable | Reverse Face намеренно без аудиоподсказки |
| Контент | короткий; длинный; много значений; идиома-only; sparse; rich; длинное слово | Не каждая комбинация требует отдельного макета |
| Размер | узкий мобильный; базовый 402×874; desktop; короткий по высоте экран | Breakpoints/max-height новой версии: —; Retina сама по себе не определяет размер |
| Тема | light; dark | Оба профиля проверяются отдельно |
| Язык интерфейса | NL; EN; RU | Длинные подписи не обрезаются; числовой контракт не зависит от текста |
| Взаимодействие | rest; hover; keyboard focus; pressed; disabled; reduced motion | Невидимый hover на touch не заменяет focus |

Полный декартов продукт не нужно рисовать заранее. Основные комбинации получают собственные строки;
повторно используемые асинхронные состояния — общие правила с проверкой применимости.
Ни одно непроверенное сочетание не считается покрытым только потому, что похожая картинка существует.
