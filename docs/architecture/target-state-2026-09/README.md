## Принятые ограничения

Продукт находится в активной разработке. Каждая миграция заканчивается удалением заменённого активного пути.
Сохранение прежнего renderer или fallback после завершения миграции не является целевым результатом.
Исторические миграции и доказательства прошлых решений не смешиваются с активным кодом.
Инвентаризация клиентов включает AudioFilms и Pontix; платформенные изменения принадлежат 2000NL, изменения клиентов — их репозиториям.

Pen хранит изображения, варианты и историю. Матрица хранит охват решений, точные ссылки и пробелы.
Числовой контракт будет исполняться в общих стилях и реальных модулях карточки. В матрице не дублируются значения исполняемого контракта вручную после его появления.
Утверждение картинки не означает утверждение всех режимов, тем, размеров и поведения.
Новые пожелания владельца не изменяют задним числом статус исторического эталона: создаётся следующая ревизия.

## Задание, посильное агенту

Перед стартом каждому исполнителю выдаются: один issue, точная база, конкретные строки матрицы, разрешённые файлы/смысловые области,
входные примеры, результат, список удаляемого кода и проверки. Если обнаружено недостающее продуктовое решение, агент оставляет его как пробел.
Агент не назначает сам статус APPROVED и не обновляет эталон ради зелёного теста.

Root принимает решения о владении состоянием, данных и окончательном удалении; проверяет spec, архитектуру и рефакторинг.
UI-принятие продукта остаётся у владельца. За один общий файл или контракт в момент времени отвечает один исполнитель.
Разработка идёт из актуальной базы; ветки с зависимостью переоснованы после объединения предшественника.
Проверки привязаны к итоговому commit. Повторное ревью запускается после изменений или для устранения открытых замечаний, а не бесконечно по кругу.

## Критерий завершения миграции

1. Новый путь покрывает утверждённые реальные сценарии.
2. Все его callers переведены.
3. Старые реализации, переключатели, преобразования и неактуальные тесты удалены.
4. Запрет старого пути проверяется по конкретным импортам/вызовам, а не по слову legacy во всём репозитории.
5. Применимые ADR, документация и матрица указывают на тот же результат.
6. Интеграция и проверка runtime подтверждены отдельно от review-ready.
